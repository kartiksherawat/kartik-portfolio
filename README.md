# Kartik Sherawat Portfolio

## Deploy to Netlify
1. Put `index.html`, `style.css`, `script.js`, and your real `resume.pdf` in the same folder.
2. Push the folder to GitHub.
3. In Netlify, choose **Add new project → Import an existing project → GitHub**.
4. Select the repository.
5. For this plain HTML/CSS/JS site, leave build command empty and publish directory as `/`.
6. Deploy.

## Before publishing
- Add your actual `resume.pdf` to the root.
- Replace the placeholder email `kartiksherawat@gmail.com` with your preferred public email if different.
- Review project descriptions and metrics against your CV.
